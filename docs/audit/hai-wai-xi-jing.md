# Audit — 海外西經

Per-entry record of **what was excluded** and why. This is the safety net: it lets anyone see every character dropped, and challenge the rule.

Rule applied: *include a clause if it asserts a spatial relation between two named places.* Everything below asserts no spatial relation.

Source: zh.wikisource, `山海經/海外西經` (郭璞注 removed).
